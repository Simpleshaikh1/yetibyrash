# Button

Buttons start every action, and their label says exactly what happens.

- **Primary**: `ink` fill, `ink-on-dark` text, `radius-pill`, 52px tall. One per screen. Add the amount when money is involved: "Add to bag · ₦14,500".
- **Outline**: `surface-card` fill, 1px `line-shop` border, `ink` text. For "Continue shopping", "Keep shopping", filters.
- **Pay with Paystack**: primary style with a lock icon, label "Pay ₦29,000 with Paystack", and the line "Card, bank transfer or USSD on Paystack's secure page." underneath.
- **Admin**: `radius-field`, 44px tall. Primary is `ink`; secondary is white with a `line-field` border.

The consumer provides the label, the icon (optional) and the link or handler.
