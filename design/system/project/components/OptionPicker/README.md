# OptionPicker

Colour swatches and size buttons on the product page, driven by the admin's colour list and size sets.

- Label line first: "Colour: **Espresso**", "Size (UK)" with a "Size guide" link on the right.
- Colour swatches: 44px circles. Selected: 2px `ink` ring with a 3px gap in the ground colour. Unselected: 1px `line-shop` border.
- Size buttons: equal columns, 44px tall, `radius-md`. Selected: `ink` fill, `ink-on-dark` text. Unselected: `surface-card` with a `line-shop` border. Sold-out sizes: struck through in `ink-muted` and not tappable, unless pre-order is on.
- Products with one size (watches, bags, earrings) show no size row; bags show dimensions instead.

The consumer provides the options from the product's colour and size set, the selection and the stock per option.
